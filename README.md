# Omudaala

Modern Uganda online marketplace starter.

## Included
- Modern blue/orange marketplace homepage
- Product catalogue with New/Used, UGX prices, seller phone numbers
- Buyer login/registration UI and saved products
- Shopping cart UI
- Seller dashboard
- Subscription plans with configurable payment placeholder
- Product posting form
- Admin panel UI
- Responsive mobile-first design

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Production next steps
Connect authentication/database, image storage, orders, reviews, seller subscriptions and a Uganda-supported payment provider. Replace the demo data in `index.html` with API/database data.
